# 财务自由计算器（FIRE）

基于 **4% 原则** 与 **复利增长模型** 的财务自由（FIRE）进度计算器，纯静态单页网页（HTML + CSS + 原生 JS），可直接部署到 GitHub Pages。

## 功能

- 输入当前年龄、现有资产、每月新增投入、自由后每月开支、预期年化收益率、预期通胀率
- 计算自由所需资产（自由后年开支 ÷ 4%）
- 预测自由年龄、自由日期、距今年数
- 展示财富增长走势图与逐年预测表（年份 / 年龄 / 累计本金 / 资产总额 / 进度）

## 计算口径

- 目标资产 = 自由后每月开支 × 12 ÷ 4%
- 实际年化收益 = 预期年化收益率 − 预期通胀率
- 按月度复利 + 每月定投逐年累积，直至资产总额达到目标

## 使用

直接用浏览器打开 `index.html`，或访问 GitHub Pages 地址。所有计算均在本地浏览器完成，不发送任何数据。

> 计算结果基于用户填写的假设参数估算，仅供参考，不构成投资建议。
